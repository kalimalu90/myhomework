# تطبيق منتجات Laravel - Product Management Application

تطبيق حديث لإدارة المنتجات مع دعم كامل لتعدد اللغات (العربية والإنجليزية) ورفع الصور. يجمع التطبيق بين تقنيات العصر الحديثة مثل React للواجهة الأمامية و Express مع tRPC للخادم الخلفي.

## المميزات الرئيسية

يوفر التطبيق مجموعة شاملة من الميزات المصممة لتسهيل إدارة المنتجات:

**إدارة المنتجات**: إنشاء منتجات جديدة مع اسم وصف مفصل وصورة عالية الجودة. عرض قائمة شاملة بجميع المنتجات مع معاينة الصور. الوصول إلى تفاصيل كل منتج بسهولة.

**نظام تعدد اللغات**: دعم كامل للعربية والإنجليزية مع واجهة سهلة لتبديل اللغات. جميع النصوص والرسائل مترجمة بعناية.

**التحقق من البيانات**: التحقق من صحة اسم المنتج (3 أحرف على الأقل). التحقق من وصف المنتج (10 أحرف على الأقل). التحقق من صيغة الصورة (JPG أو PNG فقط) وحجمها (بحد أقصى 2MB).

**واجهة مستخدم حديثة**: تصميم نظيف وبسيط يسهل الاستخدام. دعم الأجهزة المختلفة (Responsive Design). تجربة سلسة وسريعة.

## خطوات التثبيت والتشغيل

### الخطوة الأولى: استنساخ المشروع

ابدأ بتحميل المشروع من المستودع:

```bash
git clone <repository-url>
cd laravel-product-app
```

### الخطوة الثانية: تثبيت الحزم

استخدم pnpm لتثبيت جميع المكتبات المطلوبة:

```bash
pnpm install
```

إذا كنت تستخدم npm بدلاً من pnpm:

```bash
npm install
```

### الخطوة الثالثة: إعداد متغيرات البيئة

أنشئ ملف `.env` في جذر المشروع وأضف المتغيرات التالية:

```env
DATABASE_URL="mysql://username:password@localhost:3306/product_app"
JWT_SECRET="your-secret-key-here"
VITE_APP_ID="your-app-id"
OAUTH_SERVER_URL="https://api.manus.im"
VITE_OAUTH_PORTAL_URL="https://portal.manus.im"
```

**ملاحظة مهمة**: استبدل القيم بقيمك الخاصة. يمكنك الحصول على معرف التطبيق من لوحة التحكم.

### الخطوة الرابعة: إعداد قاعدة البيانات

شغّل الهجرات لإنشاء جداول قاعدة البيانات:

```bash
pnpm db:push
```

هذا الأمر سيقوم بإنشاء جميع الجداول المطلوبة تلقائياً.

### الخطوة الخامسة: تشغيل التطبيق

ابدأ خادم التطوير:

```bash
pnpm dev
```

سيظهر رابط الوصول إلى التطبيق في الطرفية (عادة `http://localhost:3000`).

## استخدام التطبيق

### الصفحة الرئيسية

عند فتح التطبيق، ستظهر الصفحة الرئيسية التي تحتوي على ترحيب ورابط سريع للمنتجات.

### عرض المنتجات

اذهب إلى قسم "المنتجات" لرؤية جميع المنتجات المضافة. يتم عرض كل منتج في بطاقة تحتوي على صورة واسم وجزء من الوصف.

### إضافة منتج جديد

انقر على زر "إضافة منتج" واملأ النموذج بالمعلومات التالية:

- **اسم المنتج**: يجب أن يكون 3 أحرف على الأقل
- **الوصف**: يجب أن يكون 10 أحرف على الأقل
- **الصورة**: يجب أن تكون بصيغة JPG أو PNG وحجمها أقل من 2MB

### عرض تفاصيل المنتج

انقر على أي منتج في القائمة لرؤية تفاصيله الكاملة بما في ذلك الصورة الكاملة والوصف الكامل.

### تبديل اللغة

استخدم القائمة المنسدلة في شريط التنقل لتبديل بين العربية والإنجليزية. سيتم حفظ اختيارك تلقائياً.

## استكشاف الأخطاء

### المشكلة: لا يمكن الاتصال بقاعدة البيانات

**الحل**: تحقق من أن قيمة `DATABASE_URL` في ملف `.env` صحيحة وأن خادم قاعدة البيانات يعمل.

### المشكلة: الصور لا تظهر

**الحل**: تأكد من أن الصور تم رفعها بصيغة صحيحة (JPG أو PNG) وأن حجمها أقل من 2MB.

### المشكلة: الترجمات لا تعمل

**الحل**: تأكد من أن ملفات الترجمة موجودة في مجلد `client/public/locales/` وأن أسماء الملفات صحيحة.

### المشكلة: خطأ عند تشغيل `pnpm dev`

**الحل**: جرب الخطوات التالية:

1. احذف مجلد `node_modules` وملف `pnpm-lock.yaml`
2. شغّل `pnpm install` مرة أخرى
3. شغّل `pnpm dev`
